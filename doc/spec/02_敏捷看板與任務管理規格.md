# 第 02 章：敏捷看板與任務管理規格

## 2.1 敏捷看板視圖 (Kanban Board)
1. **多專案切換**：頂部導航欄提供專案切換下拉選單，看板資料依所選專案即時過濾。
2. **欄位動態維護**：
   - 各專案擁有獨立的看板欄位流程（例如「待處理 (To Do)」、「進行中 (In Progress)」、「待審核 (Under Review)」、「已完成 (Done)」）。
   - 欄位支援新增、刪除、自訂標題與自訂顏色（如 `#64748b`, `#2563eb`, `#d97706`, `#16a34a`）。
   - 具有 `is_done: true` 屬性之欄位，其內任務視為已結案。

---

## 2.2 任務規格 (Task Specifications)
1. **任務編碼機制**：
   - 格式：`TSK-{001}`（例如 `TSK-101`, `TSK-102`），以目前任務數量累加自動產生。
2. **優先等級 (Priority)**：
   - 支援四級：`URGENT`（緊急，紅色）、`HIGH`（高，橙色）、`MEDIUM`（中，黃色）、`LOW`（低，綠色）。
3. **工期與人員配置**：
   - 包含開始日期 (`start_date`) 與截止日期 (`due_date`)。
   - 主負責人 (`assignee_id`)：單一主要指派對象。
   - 協同人員 (`collaborator_ids`)：支援複選多位協同工程師。
4. **工程標籤 (Tags)**：支援多標籤分類（如 `BIM套圖`, `管線干涉`, `現場施工`, `耐壓測試`）。
5. **施工圖面與附件關聯**：
   - 任務支援關聯圖面或現場照片附件（`target_type: 'TASK'`）。
   - 點選附件支援圖片燈箱檢視器 (Lightbox Viewer) 全螢幕放大瀏覽。
6. **任務拖曳與狀態變更**：
   - 支援拖曳任務卡片跨欄位移動，並同步更新排序位置 (`position`)。
   - 移動或編輯任務時，系統自動產生審計活動日誌。
