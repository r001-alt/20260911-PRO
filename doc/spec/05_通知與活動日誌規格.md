# 第 05 章：通知與活動日誌規格

## 5.1 即時通知中心 (Notification Center)
1. **通知類型 (`type`)**：
   - `TASK_ASSIGNED`：當任務被指派給特定工程師時觸發。
   - `RFI_SUBMITTED`：當工程師提送新 RFI 並指定審查顧問時觸發。
   - `RFI_ANSWERED`：當審查顧問發布官方技術回覆時，通知 RFI 提送人。
2. **狀態與互動規格**：
   - 包含未讀計數角標 (Badge)。
   - 支援單筆通知標記已讀 (`PATCH/PUT /api/v1/notifications/:id/read`)。
   - 支援「全部標記為已讀」(`PUT /api/v1/notifications/read-all`)。
   - 點擊通知項目自動切換至關聯之任務或 RFI 詳情。

---

## 5.2 審計活動日誌 (Activity Audit Trail)
1. **記錄維度**：
   - 時間戳記 (`created_at`)、專案 ID (`project_id`)、執行人員 ID 與姓名 (`user_name`)。
   - 動作類型 (`action`)：例如「建立了新任務」、「將任務狀態推進至已完成」、「回覆並簽核了 RFI」。
   - 目標標題與類型 (`target_title`, `target_type`)。
2. **應用場景**：
   - 專案活動歷史軌跡檢視。
   - 工務例會或驗收結案時之履約歷史追溯。
