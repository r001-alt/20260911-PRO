# 專案工程文件中心 (Documentation Center)

本目錄為本營建機電專案管理系統之規格架構與開發計畫庫，包含兩大核心目錄：

```
doc/
├── dev/     # 開發計畫區：新功能開發前撰寫之計畫 (plan_<功能名稱>.md)
└── spec/    # 規格說明區：分章節維護之系統與各模組最新規格
```

---

## 📌 核心協作流程準則

1. **先討論後計畫**：
   - 任何功能開發前，先與團隊/使用者討論釐清需求。
   - 討論定案後，於 `doc/dev/` 建立開發計畫，檔案格式統一命名為：
     `plan_<功能名稱>.md` (例如 `doc/dev/plan_rfi_pdf_export.md`)。
2. **依計畫實作**：
   - 開發過程隨時參照 `doc/dev/plan_<功能名稱>.md`，確保符合最初設計與架構。
3. **完成後回寫規格**：
   - 功能實作完成且驗證無誤後，**必須將最新功能規格回寫並同步至 `doc/spec/` 對應章節**。
   - `spec` 採分章節撰寫與維護，維持模組獨立性與文檔最新性。
